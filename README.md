# Everyday Issue Tracker

Niche: software engineers who feel empowered and eager to get their work done, but can't seem to get to their everyday tasks. 

## Description 

This issue tracker is built like Linear/Jira/Trello but designed for day-to-day personal use. If you're driven by moving tasks across a board during your 9-5, this might help you get things done after you log off.
